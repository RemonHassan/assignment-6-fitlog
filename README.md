# FitLog — Modern Workout & Fitness Tracker

**FitLog** is a high-performance, responsive fitness management web application designed to help users browse, organize, and track their daily workouts effortlessly. Built with Next.js (App Router), TypeScript, and Tailwind CSS, FitLog delivers an intuitive user experience featuring live statistics, dynamic plan customization, and custom dark/neon aesthetics.

---

## ⚡ Key Features

- **Interactive Exercise Library & Dynamic Details** — Browse an extensive workout catalog and view detailed breakdowns for each exercise, including step-by-step instructions, calorie estimates, set/rep targets, and required equipment.
- **Daily Plan Management** — Build custom daily workout routines on the fly with real-time feedback. Users can add exercises, remove items, or complete workouts using the interactive "Mark as Done" functionality.
- **Saved Workouts Library** — Bookmark exercises to a dedicated "Saved for Later" collection and seamlessly move them into active daily plans with a single click.
- **Live Analytics Dashboard** — Real-time stat aggregation that dynamically computes and updates total exercises, total duration (minutes), and total calories burned based on the active tab context.
- **Multi-Criteria Sorting & Tab Filtering** — Organize routines effortlessly by switching between active "Today's Plan" and "Saved" lists, with sorting options by **Duration**, **Calories**, and **Rating**.

---

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router, Server & Client Components)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) & [DaisyUI](https://daisyui.com/)
- **Icons:** [React Icons](https://react-icons.github.io/react-icons/)
- **State Management:** React Context API (`WorkoutContext`)
- **Notifications:** [React Toastify](https://fkhadra.github.io/react-toastify/)
